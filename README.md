# my-website

デジたぬ研 — a personal daily-art wall.

このリポジトリは静的な `index.html` 1枚だけで構成されています。
データの保存にはFirebaseを使っているため、公開の前に `index.html` 内の
`firebaseConfig` を自分のFirebaseプロジェクトの値に置き換えてください
（詳しい手順は元のセットアップ手順書 `SETUP.md` を参照）。

## 公開URL

GitHub Pagesを有効にすると、以下のようなURLで公開されます：

```
https://<あなたのGitHubユーザー名>.github.io/my-website/
```
